How to use

The software is downloadable and can be run through terminal using argeparse commands, or through the TUI interface. The TUI interface is the most user-friendly and is recommended for most users. There is a help command to display the commands to those using through a terminal.

To run the TUI you must get your terminal into the same directory as the file App.py and then run the command:

Textual run App.py
