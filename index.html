Wikipedia-Name-Query

Introduction

This project allows users to query DBpedia using a person's name to retrieve key biographical information.

Core Technologies

    Textual

    – for the user interface

    SQLite3

    – for database storage

    SPARQLQuery

    – to fetch data from DBpedia

The code querys dbpedia using a persons name and retreives their full name, date of birth, and date of death. this then stores the data in a list and calculates the persons age. the data is then displayed on the UI in a table format. The UI is a data table with buttons around the edge that allows the user to input names, files and delete data and all the data is stored in a sqlite database.
